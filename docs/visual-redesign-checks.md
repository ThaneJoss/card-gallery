- 逐张加载、解码并查看真实图片，检查浅色、深色、竖版和长名称素材。展台比例一致，卡面等比完整展示，长名称可自然换行。用户随后补充要求保留银行卡式圆角，现已改为列表卡面 10px、大图卡面 16px；圆角贴合图片实际边缘，覆盖原方案中不强加卡面圆角的要求。

- 使用只存在于浏览器测试中的超长标题检查：标题完整换行，内容区可滚动，滚到末尾时关闭区仍可见。测试没有写入卡片数据。
- 开启减少动态效果后，卡面位移、过渡和弹层淡入均停用。
- 原有图片加载失败、空收藏和卡片数据加载失败状态均通过浏览器临时请求模拟检查。
- 浏览器运行期间未捕获 JavaScript 异常。
